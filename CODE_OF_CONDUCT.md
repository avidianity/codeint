# Code of Conduct

## Our commitment

We want codeint to be a welcoming, constructive, and safe project for everyone.
Participation is open to all contributors regardless of background, identity, or experience level.

## Expected behavior

- Communicate with respect, clarity, and patience.
- Focus feedback on code, design trade-offs, and evidence rather than on people.
- Accept constructive criticism gracefully.
- Respect the time and boundaries of maintainers and fellow contributors.

## Unacceptable behavior

- Harassment, personal attacks, insults, or discriminatory language.
- Publishing another person's private information without permission.
- Trolling, deliberate disruption, or bad-faith engagement in issues or pull requests.
- Any other conduct that creates an unsafe or hostile environment.

## Scope

This Code of Conduct applies across all project spaces, including GitHub issues, pull requests, discussions, and commits.

## Reporting

If you experience or witness unacceptable behavior, report it privately through the repository's [GitHub Security tab](https://github.com/avidianity/codeint/security) or by contacting the repository maintainers via GitHub.
Maintainers review every report and may warn, remove comments from, or ban contributors who violate this policy.
