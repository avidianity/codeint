# Changelog

## 0.8.0

- Initial release of the pure Dart `codeint` client SDK and CLI runner.
- Full 18-operation programmatic API covering all 17 non-interactive CLI commands.
- Four-step SHA-256-verified native binary resolver with local cache and offline CI mode (`allowDownload: false`).
- Executable forwarders `dart run codeint` and `dart run codeint:install`.
