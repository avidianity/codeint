# Feature maps

This folder holds one Feature map per user-visible command of `codeint`.
Every Feature map uses the operations in [docs/verification/README.md](../README.md).

| Feature | Command | Feature map |
| ------- | ------- | ----------- |
| Working-tree measurement | `codeint check` | [check.md](./check.md) |
| Branch and ref comparison | `codeint diff` | [diff.md](./diff.md) |
| Main-line commit history | `codeint trend` | [trend.md](./trend.md) |
| Starter configuration | `codeint init` | [init.md](./init.md) |
